## Verdicts

**Theorem D′.** Holds with fixes. The synchronous-coupling proof of (b) is correct (noise cancels exactly because the diffusion
coefficient √(2τ)G^{1/2} is the same constant for both systems; L_b is assembled correctly; all metrics are Euclidean and
consistent; the variance bound and the Grönwall/sup step are right). One stated inequality is not proved as written: the
per-particle **sup-in-time** bound in (c), first bullet, does not follow from exchangeability (D1). The "dimension-independent
constants" wording is an overclaim since K_Φ = a_max√n (D3). The numerical "check" is not yet supported by the table on disk
(slopes −0.25/−0.21 vs −0.5 from 3 seeds); my diagnosis is that sup_t D_m is a non-self-averaging statistic, so the exponent
needs many seeds — with 12 seeds the slope is −0.54 ± 0.07 (D2). The parent's updated `exp_chaos.py` already moves in this
direction; the table and the Numerics paragraph still have to be produced from it.

**Theorem C′.** Holds with fixes. (i)–(v) are correct as inequalities, the code implements the law as stated (G⁻¹ metric
throughout, LP constraints right, Var formula right, Pythagorean split exact), and the Numerics paragraph quotes the table
correctly up to one rounding slip. Two things need repair: the ω-limit argument in (i) is not a valid inference as written
(C1; the conclusion is true and a short LP-stability argument proves it without the "finitely many switches" assumption), and
the novelty claim "new as a control construction" is an overclaim (continuous-time Lloyd descent is the classical
coverage-control law) (C2). The local clauses (ii)–(iv) are vacuous on the experiment's instances and the text should say so
(C3).

## Details

### Theorem D′ — what was checked and found correct

- Coupling: same B_i, same ϑ_i(0), deterministic x̄_0; x̄ is deterministic because μ̄_t = Law(ϑ̄_t) is a fixed measure and x̄ solves an ODE with deterministic input from deterministic x̄_0 (this also forces any random x̄ solving (MV) to be deterministic by ODE uniqueness). The noise cancels exactly in dΔ_i because both diffusion coefficients are the same constant √(2τ)G^{1/2}; Δ_i is absolutely continuous and d‖Δ_i‖/dt ≤ ‖Δ̇_i‖ a.e.
- L_b: ∂_e b = G(∇_ϑΦ̃)ᵀ (norm ≤ λ_G L_ϑ, no E_X since b is linear in e), ∂_x b = G ∂_x∇_ϑ[eᵀΦ̃] (≤ λ_G E_X sup‖∂_x∇_ϑΦ̃‖), ∂_ϑ b = G∇²_ϑ[eᵀΦ̃] − σI (≤ λ_G E_X sup‖∇²_ϑΦ̃‖ + σ). The factor λ_G = λ_max(G) is right for Euclidean norms. The e-ball {‖e‖ ≤ E_X} is convex so the segment argument is fine in e; in x the Φ̃-derivative bounds are global.
- Metric consistency: Δ̄ is a Euclidean mean, L_ϑ is the Euclidean operator-norm Lipschitz constant of ϑ ↦ Φ̃(x;ϑ), ‖∫Φ̃ d(μ − μ′)‖ ≤ L_ϑ W₁ with Euclidean W₁ (needs P₁ ⊃ P₂, fine). No G⁻¹/Euclidean mismatch inside D′; the mismatch with the rest of the paper is notational (D7).
- Variance: the ϑ̄_j are strong solutions F(ϑ_j(0), B_j) of the same SDE with deterministic coefficients, hence i.i.d.; E‖(1/m)Σ(Z_j − EZ_j)‖² = (1/m)E‖Z_1 − EZ_1‖² ≤ K_Φ²/m. E∫ζ ≤ ∫(Eζ²)^{1/2} ≤ TK_Φm^{−1/2} (Tonelli + Jensen); E(∫ζ)² ≤ T∫Eζ² (Cauchy–Schwarz).
- Grönwall: Ḋ ≤ (L_f + L_x + 2L_b)‖δ‖ + (L_ϑ + L_b)Δ̄ + ζ ≤ ΛD + ζ, D(0) = 0 since x(0) = x̄_0 and ϑ_i(0) = ϑ̄_i(0); the right-hand side e^{Λt}∫₀^tζ is non-decreasing, so the sup can be taken inside the expectation.
- Standing bound: the e-ODE holds pathwise with ‖f̂‖ ≤ K_Φ for every parameter configuration (saturation), so D(b)'s first-exit argument gives a deterministic tube for every m and realisation; "local in time otherwise" is also deterministic because the input is bounded. The chaos plant f = sin 2x + 0.3x has linear growth 0.3 < k_e, so the tube applies there.
- (c) second bullet: the three-term split bounds f̂^m(x_t) − ∫Φ̃(x̄_t;·)dμ̄_t by (L_x + L_ϑ)D(t) + ζ_t; E D(t) ≤ TK_Φe^{ΛT}m^{−1/2}, Eζ_t ≤ K_Φm^{−1/2}. Third bullet: identity coupling + triangle inequality; Fournier–Guillin Thm 1 gives E W₁ = O(m^{−1/p}) for p > 2 under a q-th moment with q ≥ p/(p−1), satisfied by q = 2. (d) uses nothing from τ > 0.
- Code: `exp_chaos.py` implements the coupling as described (same `Th_all[:m]`, same `noise[:m]`, same x(0) = x_ref(0), Euler–Maruyama with √(2τ dt)G^{1/2}N(0,1), RK4 for the plant), D_m in the Euclidean norm. In my runs every particle attains its sup at the same time as the mean (ratio mean_i sup_t‖Δ_i‖ / sup_t Δ̄ = 1.00–1.04), so D1 has no numerical consequence here; it is a proof gap.

### Theorem D′ — on D2

Time profile (seed 0, τ = 0, T = 20): |e^M| oscillates at 0.01–0.1; D_16 grows slowly to 0.12 (its particles accumulate error since σ = 0.02 gives no parameter contraction), D_64, D_256, D_1024 plateau at 0.010, 0.014, 0.017 from t ≈ 5. The ratio sup_t D_m / ∫₀^T ζ^{m,M} is 0.1 for every m, i.e. the Grönwall factor e^{ΛT} is irrelevant and the loop is contracting; what varies between seeds is the forcing itself, a time-persistent function of which particles happen to be in the first m. Hence (i) 3 seeds are far too few, (ii) sup_t over a plateau is a poor statistic (the RMS over t has the same mean scaling and less variance), (iii) the (1/m − 1/M)^{1/2} normalisation is the right one, and (iv) T can be short. The 12-seed, T = 5, M = 2048 run reproduces the predicted exponent within error (−0.54 ± 0.07). The current 3-seed table should not be quoted.

### Theorem C′ — what was checked and found correct

- (i): the competitor argument (γ couples μ_{t+h} and ν since row sums are 1/m; equality at h = 0) gives D⁺Z ≤ Σγ_ij⟨ϑ_i − ϑ⁰_j, G⁻¹ϑ̇_i⟩; Σ_jγ_ij(ϑ_i − ϑ⁰_j) = (1/m)(ϑ_i − T̄_i) because Σ_jγ_ij = 1/m and T̄_i = mΣ_jγ_ijϑ⁰_j. Θ_K^ε = ball × ball × interval is convex, so T̄_i (a convex combination of points of Θ_K^ε; for general ν, the barycentre of a probability measure on a closed convex set) lies in Θ_K^ε and (P) applies with ϑ′ = T̄_i. Pythagoras follows from Σ_jγ_ij(ϑ⁰_j − T̄_i) = 0 in the bilinear G⁻¹ form (numerically exact to 1e-16). Z is AC without any switching assumption (min of finitely many Lipschitz functions along an AC path), so "W non-increasing" is fine; only the ω-limit clause needs C1. Envelope theorem: at a configuration with a unique optimal plan ½W² is differentiable with ∂_{ϑ_i} = (1/m)G⁻¹(ϑ_i − T̄_i) (Danskin), so the pure leak is ϑ̇_i = −σ_m m G∂_{ϑ_i}[½W²], the G⁻¹-metric gradient flow; "critical points where differentiable" is consistent with non-differentiability at ties.
- (ii): the L²(ρ) triangle inequality with matched labels gives |√c_ρ(ϑ) − √c_ρ(ϑ*)| ≤ η for any ρ with row sums 1/m; C_bar ≤ c_γ(ϑ*) by the same Pythagoras with the barycentres of γ; the chain uses optimality of γ at ϑ and of γ* at ϑ*. Equality case: vertex costs at ϑ* lie in {b²} ∪ [b² + Δ_gap(t), ∞), so c_γ(ϑ*) < b² + Δ_gap(t) forces optimality; with γ*(t) unique, γ = γ* and C_bar = b_bar(t)². Δ_gap is defined between vertex costs; the vertex property of γ is what the bracket supplies (C4).

- (v): b_bar² = W² − Var_{γ*} ≤ W², equality iff Var_{γ*} = 0; b_bar = 0 iff ϑ*_j = T̄*_j.

Tests check what the Checked paragraph says (90 configurations = 30 trials × 3 scales; 24-atom prior; 5 % Euler tolerance on D⁺(W²) ≤ −2σ_mV_bar²).

### Theorem C′ — overclaims

"Lloyd's algorithm in continuous time" is correct as a description (equal-mass variant, with the Pomet–Praly projection) but is not new as a control law (C2). "Proved and checked" is acceptable for (i)–(iii) and (v); (iv) is explicitly excluded from the checked list at the end of §7 and has no instance satisfying its hypotheses in the repository (C3), unlike Theorem C(iv), for which the text advertises a fully admissible instance.
